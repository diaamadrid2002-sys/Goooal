# تطبيق متابعة الهدف (APK)

هذا مشروع أندرويد بسيط يضم ملف HTML الأصلي داخل التطبيق عبر WebView. يحتفظ التطبيق بالبيانات محليًا باستخدام DOM Storage/localStorage، ويحتاج الإنترنت فقط لتحميل خط Google Fonts الخارجي إن توفر.

## بناء APK عبر GitHub
1. أنشئ مستودعًا جديدًا على GitHub وارفع جميع محتويات هذا المجلد إليه (بما فيها `.github/workflows/build-apk.yml`).
2. افتح تبويب Actions في المستودع.
3. اختر `Build Android APK` ثم `Run workflow`، أو انتظر انتهاء البناء التلقائي بعد رفع الملفات إلى فرع `main`.
4. افتح نتيجة التشغيل الناجحة، وانزل إلى قسم Artifacts، ثم نزّل `Mutabaat-Alhadaf-APK.zip`.
5. فك الضغط على الهاتف وثبّت `app-debug.apk`. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

هذه نسخة Debug للتثبيت الشخصي وليست إصدارًا موقّعًا للنشر في Google Play.
